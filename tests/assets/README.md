# Facecam test photograph

`facecam_sample.jpg` is a resized copy of scikit-image's `astronaut.png`, an image
of astronaut Eileen Collins, credited to NASA (public domain). Retrieved from
https://github.com/scikit-image/scikit-image/blob/v0.19.3/skimage/data/astronaut.png
for face-detection regression testing. No endorsement is implied. Tests composite
this still photograph onto a synthetic gameplay background; they do not claim
that fixture is actual gameplay or a human-edited example.
